# Tutorial Approfondito su Cartopy e Mappe Geospaziali con Python

---

## 1. Introduzione a Cartopy

**Cartopy** è una libreria Python potente e flessibile per la visualizzazione di dati geografici. Si basa su Matplotlib e supporta molte proiezioni cartografiche, con funzionalità per tracciare mappe, aggiungere caratteristiche geografiche, e visualizzare dati con coordinate geospaziali.

**Perché Cartopy?**

* Facile integrazione con Matplotlib
* Supporta molte proiezioni cartografiche (Plate Carree, Mercatore, Lambert, ecc.)
* Facile da usare con dati geospaziali (lat/lon)
* Include funzionalità per sovrapporre dati (punti, linee, poligoni)
* Aggiunta di elementi geografici come coste, confini, fiumi, ecc.

## 3. Nozioni Base di Proiezioni Cartografiche

Le mappe rappresentano la superficie curva della Terra in forma piana. Per farlo usano **proiezioni** che trasformano le coordinate geografiche (latitudine, longitudine) in coordinate 2D sulla mappa.

Alcune proiezioni comuni in Cartopy:

| Proiezione         | Uso tipico                                                     |
| ------------------ | -------------------------------------------------------------- |
| `PlateCarree`      | Proiezione equidistante semplice, mappa base (lat/lon diretto) |
| `Mercator`         | Mappe marine, navigazione                                      |
| `LambertConformal` | Mappe aeronautiche, meteo                                      |
| `Orthographic`     | Vista "globo" come sfera                                       |

---

## 4. Creare una Mappa Base

```python
import matplotlib.pyplot as plt
import cartopy.crs as ccrs

plt.figure(figsize=(10,6))

# Crea un oggetto Axes con proiezione PlateCarree (lat/lon semplice)
ax = plt.axes(projection=ccrs.PlateCarree())

# Disegna linee di costa
ax.coastlines()

plt.title("Mappa Base con Cartopy (PlateCarree)")
plt.show()
```

---

## 5. Aggiungere Caratteristiche Geografiche

Cartopy include molte **feature** geografiche predefinite:

* Coste
* Confini nazionali
* Stati
* Fiumi
* Laghi
* Aree urbane

```python
import cartopy.feature as cfeature

plt.figure(figsize=(12,8))
ax = plt.axes(projection=ccrs.PlateCarree())

ax.coastlines(resolution='110m')  # più dettagliata
ax.add_feature(cfeature.BORDERS, linestyle=':')
ax.add_feature(cfeature.LAKES, alpha=0.5)
ax.add_feature(cfeature.RIVERS)

plt.title("Mappa con Coste, Confini, Laghi e Fiumi")
plt.show()
```

## 6. Tracciare Punti Geografici (es. Terremoti)

Se hai dati con latitudine e longitudine, puoi visualizzarli con `scatter`.

```python
import pandas as pd

# Esempio: dati terremoti simulati
data = {
    'latitude': [37.77, 34.05, 40.71, 35.69],
    'longitude': [-122.42, -118.24, -74.00, 139.69],
    'magnitude': [4.5, 3.8, 2.9, 5.2]
}
df = pd.DataFrame(data)

plt.figure(figsize=(12,8))
ax = plt.axes(projection=ccrs.PlateCarree())
ax.coastlines()

# Scatter con magnitudo che colora i punti
sc = ax.scatter(df['longitude'], df['latitude'],
                c=df['magnitude'], cmap='Reds', s=100,
                alpha=0.7, transform=ccrs.PlateCarree())

plt.colorbar(sc, label='Magnitudo')
plt.title('Posizioni Terremoti')
plt.show()
```

---

## 7. Zoomare su un’Area Specifica

Per centrare e zoomare la mappa su una regione, puoi usare:

```python
ax.set_extent([xmin, xmax, ymin, ymax], crs=ccrs.PlateCarree())
```

Dove:

* `xmin`, `xmax` sono longitudini (es. 10, 20)
* `ymin`, `ymax` sono latitudini (es. 40, 50)

Esempio: zoom sull’Italia

```python
ax.set_extent([6, 19, 36, 47], crs=ccrs.PlateCarree())
```

## 9. Tracciare Linee e Poligoni

Oltre a punti, puoi disegnare linee e poligoni con Geometrie di Shapely:

```python
from shapely.geometry import LineString
import cartopy.io.shapereader as shpreader
import cartopy.feature as cfeature

line = LineString([(-120, 35), (-115, 40), (-110, 38)])

plt.figure(figsize=(10,6))
ax = plt.axes(projection=ccrs.PlateCarree())
ax.coastlines()

# Disegna linea
ax.plot(*line.xy, color='blue', linewidth=2, transform=ccrs.Geodetic())

plt.title("Linea geospaziale")
plt.show()
```

## 10. Usare Dataset Shapefile

Cartopy può caricare shapefile (formato GIS):

```python
shapefile_path = 'path/to/shapefile.shp'
shape_feature = cfeature.ShapelyFeature(
    shpreader.Reader(shapefile_path).geometries(),
    ccrs.PlateCarree(),
    edgecolor='black',
    facecolor='none')

ax.add_feature(shape_feature)
```

## 11. Esempio Completo: Mappa con Dati Realistici

```python
import matplotlib.pyplot as plt
import pandas as pd
import cartopy.crs as ccrs
import cartopy.feature as cfeature

# Carica dati terremoti (usa il tuo CSV)
df = pd.read_csv('terremoti.csv')

ax = plt.axes(projection=ccrs.PlateCarree())

ax.coastlines(resolution='50m')
ax.add_feature(cfeature.BORDERS, linestyle=':')
ax.add_feature(cfeature.LAKES, alpha=0.5)
ax.add_feature(cfeature.RIVERS)

sc = ax.scatter(df['longitude'], df['latitude'],
                c=df['magnitude'], cmap='hot', s=60,
                alpha=0.7, transform=ccrs.PlateCarree())

plt.colorbar(sc, label='Magnitudo')
plt.title('Terremoti negli USA')
plt.show()
```

## 🧠 1. Cos’è una matrice di correlazione

Una **matrice di correlazione** è una tabella che mostra la **forza e la direzione** delle relazioni lineari tra variabili numeriche.
Ogni cella contiene il **coefficiente di correlazione** tra due variabili.

### 🔹 Il coefficiente di correlazione di Pearson (il più comune):

[
r = \frac{\text{cov}(X,Y)}{\sigma_X \sigma_Y}
]

* ( r \in [-1, 1] )
* ( r = 1 ) → correlazione positiva perfetta
* ( r = -1 ) → correlazione negativa perfetta
* ( r = 0 ) → nessuna correlazione lineare

---

## ⚙️ 2. Preparazione: librerie e dataset di esempio

```python
import pandas as pd
import numpy as np
import seaborn as sns
import matplotlib.pyplot as plt

# Esempio di dataset simulato
np.random.seed(42)
df = pd.DataFrame({
    'Età': np.random.randint(20, 60, 50),
    'Reddito': np.random.randint(20000, 80000, 50),
    'Punteggio': np.random.randint(50, 100, 50),
    'Ore_studio': np.random.randint(1, 10, 50),
    'Ore_tv': np.random.randint(0, 10, 50)
})
df.head()
```

---

## 📊 3. Calcolo della matrice di correlazione

### ✅ Con Pandas:

```python
corr_matrix = df.corr()
print(corr_matrix)
```

👉 `df.corr()` calcola di default la **correlazione di Pearson**.
Puoi anche specificare altri metodi:

```python
df.corr(method='spearman')  # per correlazioni monotone
df.corr(method='kendall')   # più robusta, ma più lenta
```

---

## 🎨 4. Visualizzare la matrice di correlazione

### 🔹 Con Seaborn (heatmap)

```python
plt.figure(figsize=(8, 6))
sns.heatmap(corr_matrix, annot=True, cmap='coolwarm', center=0)
plt.title('Matrice di Correlazione (Pearson)')
plt.show()
```

* `annot=True` → mostra i valori numerici
* `cmap='coolwarm'` → scala di colori da rosso (negativo) a blu (positivo)
* `center=0` → imposta lo zero come punto neutro

### 🔹 Variante più leggibile

```python
sns.heatmap(corr_matrix, annot=True, fmt=".2f", linewidths=0.5, cmap='RdYlBu')
```

---

## 🔍 5. Interpretazione

| Valore `r`              | Significato                       |
| ----------------------- | --------------------------------- |
| 0.9 – 1.0 o -0.9 – -1.0 | Correlazione fortissima           |
| 0.7 – 0.9 o -0.7 – -0.9 | Correlazione forte                |
| 0.5 – 0.7 o -0.5 – -0.7 | Correlazione moderata             |
| 0.3 – 0.5 o -0.3 – -0.5 | Correlazione debole               |
| 0 – 0.3 o -0.3 – 0      | Correlazione molto debole o nulla |

💡 Esempio:

* `r = 0.82` tra “Reddito” e “Età” → all’aumentare dell’età, cresce il reddito.
* `r = -0.75` tra “Ore_tv” e “Punteggio” → più ore di TV → punteggio più basso.

---

## 🧮 6. Selezionare le correlazioni più forti

### 🔹 Correlazioni maggiori di una soglia

```python
threshold = 0.7
corr_pairs = corr_matrix.abs().unstack().sort_values(ascending=False)
strong_corr = corr_pairs[(corr_pairs < 1) & (corr_pairs > threshold)]
print(strong_corr)
```

→ Mostra solo le coppie di variabili con correlazione forte.

---

## 🧠 7. Gestione valori mancanti

Se il dataset contiene `NaN`, puoi usare:

```python
df.corr(min_periods=10)
```

→ Calcola la correlazione solo se ci sono almeno 10 valori validi.

Oppure rimuovere i `NaN` prima:

```python
df_clean = df.dropna()
df_clean.corr()
```

---

## 🔬 8. Correlazione non lineare

Pearson misura solo **relazioni lineari**.
Per relazioni **non lineari**, usa **Spearman** o **Kendall**:

```python
sns.heatmap(df.corr(method='spearman'), annot=True, cmap='coolwarm')
plt.title('Matrice di Correlazione (Spearman)')
plt.show()
```

---

## 📈 9. Scatter matrix (pairplot)

Per visualizzare graficamente **tutte le relazioni tra le variabili numeriche**:

```python
sns.pairplot(df)
plt.show()
```

👉 Utile per scoprire relazioni lineari o non lineari.

---

## 🧩 10. Esempio reale con un dataset con valori mancanti e duplicati

Puoi anche applicare la stessa analisi al tuo dataset `dataset_grezzo.csv` dopo averlo pulito:

```python
df = pd.read_csv('dataset_grezzo.csv')

# Convertiamo le colonne numeriche
df['Età'] = pd.to_numeric(df['Età'], errors='coerce')
df['Reddito'] = pd.to_numeric(df['Reddito'], errors='coerce')
df['Punteggio'] = pd.to_numeric(df['Punteggio'], errors='coerce')

# Rimuoviamo duplicati e NaN
df = df.drop_duplicates().dropna(subset=['Età', 'Reddito', 'Punteggio'])

# Matrice di correlazione
sns.heatmap(df.corr(), annot=True, cmap='viridis')
plt.title('Matrice di Correlazione Dataset Grezzo (Pulito)')
plt.show()
```

| Scopo                      | Descrizione                                            |
| -------------------------- | ------------------------------------------------------ |
| 🔍 Esplorazione dati       | Capire relazioni tra variabili                         |

| 🧠 Machine Learning        | Scegliere feature indipendenti per modelli predittivi  |
