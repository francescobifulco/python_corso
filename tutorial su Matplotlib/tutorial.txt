## 1. 📦 Caricamento dati

Useremo un dataset di esempio da `seaborn` chiamato **"tips"**, che contiene informazioni sulle mance nei ristoranti.

```python
import seaborn as sns
import pandas as pd

# Carica dataset di esempio
df = sns.load_dataset("tips")
print(df.head())
```

---

## 2. 📘 Cos'è un Box Plot?

Un **box plot** mostra:

* Mediana (linea centrale)
* Quartili (scatola)
* Valori estremi (baffi)
* Outlier (punti fuori dai baffi)

### ▶ Esempio di box plot

```python
import matplotlib.pyplot as plt

# Box plot del totale conto (total_bill) diviso per giorno
sns.boxplot(x="day", y="total_bill", data=df)
plt.title("Box Plot: Total Bill per Giorno")
plt.show()
```

### 📈 Quando usare:

* Per confrontare distribuzioni tra gruppi
* Per individuare outlier e asimmetrie

---

## 3. 🎻 Cos'è un Violin Plot?

Un **violin plot** include tutte le informazioni del box plot, ma in più:

* Mostra **la distribuzione dei dati** con una curva di densità

### ▶ Esempio di violin plot

```python
# Violin plot del totale conto (total_bill) per giorno
sns.violinplot(x="day", y="total_bill", data=df)
plt.title("Violin Plot: Total Bill per Giorno")
plt.show()
```

### 📈 Quando usare:

* Per vedere la **forma** della distribuzione (es: bimodalità)
* Quando vuoi più dettaglio rispetto a un box plot

---

## 4. 📊 Confronto diretto

Puoi anche **combinare** i due:

```python
plt.figure(figsize=(12, 5))

# Box plot
plt.subplot(1, 2, 1)
sns.boxplot(x="day", y="total_bill", data=df)
plt.title("Box Plot")

# Violin plot
plt.subplot(1, 2, 2)
sns.violinplot(x="day", y="total_bill", data=df)
plt.title("Violin Plot")

plt.tight_layout()
plt.show()
```

---

## 5. 🧠 Personalizzazioni utili

### Aggiungere punti individuali (swarm plot):

```python
sns.violinplot(x="day", y="total_bill", data=df, inner=None)
sns.swarmplot(x="day", y="total_bill", data=df, color="k", alpha=0.6)
plt.title("Violin Plot + Swarm (punti individuali)")
plt.show()
```

---

## 6. 💡 Box Plot vs Violin Plot – Quale usare?

| Caratteristica          | Box Plot ✅ | Violin Plot 🎻 |
| ----------------------- | ---------- | -------------- |
| Mediana                 | ✅          | ✅              |
| Quartili                | ✅          | ✅              |
| Outlier                 | ✅          | ✅              |
| Distribuzione           | ❌          | ✅              |
| Più semplice da leggere | ✅          | ❌              |
| Esteticamente ricco     | ❌          | ✅              |

---

## 7. 📂 Applicazione reale (con Pandas)

Se hai un tuo dataset:

```python
import pandas as pd

# Supponiamo tu abbia un file CSV
df = pd.read_csv("tuo_file.csv")

# Box plot di una colonna rispetto a una categoria
sns.boxplot(x="categoria", y="valore", data=df)
```

---

## ✅ Conclusione

* Usa **box plot** per confronto semplice tra gruppi
* Usa **violin plot** per vedere meglio la forma della distribuzione
* Usa entrambi insieme per analisi più ricche
